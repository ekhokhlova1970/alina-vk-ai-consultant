## [1.0.0] — 2026-11-01

Первый публичный релиз портфолио-версии проекта.

### Added

- Приём сообщений сообщества ВКонтакте через Bot Long Poll API.
- Ответы через OpenAI-совместимый Chat Completions API ProxyAPI.
- Поиск по локальной Markdown-базе знаний с синонимами предметной области.
- Отдельный системный промпт с ролью, стилем и защитой от посторонних инструкций.
- История диалога в оперативной памяти: лимит сообщений, TTL, вытеснение пользователей.
- Команды `/start`, `/help`, `/reset`, `/contact`, в том числе с упоминанием бота.
- Поддержка личных сообщений и бесед, разбивка длинных ответов.
- Fallback-ответ при ошибке ProxyAPI и переподключение Long Poll.
- Валидация всех переменных окружения при старте.
- Пакетная структура `src/alina_bot` и консольная команда `alina-bot`.
- 75 тестов без сетевых вызовов и линтер Ruff.
- CI на Python 3.10, 3.11, 3.12.
- Dockerfile с запуском от непривилегированного пользователя.
- Документация: архитектура, настройка, модель веток.

### Security

- Секреты читаются только из `.env`, который исключён из Git.
- Ключи скрыты в `repr` и не попадают в логи.
- Тексты пользовательских сообщений не логируются.
- История переписки не записывается на диск.
